# 🐾 KotoTinder — приложение для свайпа котиков  
**Автор:** Лазарева Александра, БПИ234  

## Описание проекта

**KotoTinder** — мобильное Flutter-приложение в стиле Tinder, но для котиков.  
Пользователь свайпает кошачьи карточки, ставит лайки любимым котам,  
открывает детальную информацию и просматривает список пород.

Приложение построено на **архитектуре Clean Architecture**, использует открытое API  
**TheCatAPI**, а также поддерживает красивые анимации и приятный UI и хранение данных в базе данных.

## Реализованный функционал

### Главный экран
- Получение случайного котика через `/images/search`
- Отображение фото + названия породы
- Свайп карточки влево/вправо с анимацией  
  ✔ свайп вправо = лайк  
  ✔ свайп влево = пропуск  
- Кнопки ❤️ и ❌ работают так же, как свайпы
- Счетчик лайков обновляется в реальном времени
- Тап по котику → переход к экрану деталей

### Детальный экран котика
- Квадратная большая фотография
- Плавный **Hero-переход**
- Полная информация о породе:
  - страна происхождения
  - темперамент (в виде чипов)
  - описание
  - продолжительность жизни
  - характеристики (child-friendly, dog-friendly, energy level)

### Список пород
- Отдельная вкладка в **TabBar**
- Поиск по породам
- Список всех пород из `/breeds`
- Название, страна, мини-описание
- Переход на детальную страницу породы

### Экран лайкнутых котиков
- Отображение карточек всех лайкнутых котов
- Фото, название породы, характеристики
- БД (удаление и добавление котов)

### Онбординг 

При первом запуске отображается онбординг-экран.

Он содержит несколько страниц:
1. объяснение механики свайпов
2. просмотр информации о породах
3. лайки и список любимых котиков

### Регистрация и вход

В приложении реализован authentication flow.

Login:
- email
- password
- валидация
- обработка ошибок

Sign Up:
- регистрация нового пользователя
- проверка данных
- создание аккаунта

Сохранение авторизации:

Данные пользователя сохраняются в Flutter Secure Storage / Keychain.

### Тестирование
1. Unit tests проверяют доменную логику.
2. Widget tests проверяют UI-сценарии.

### CI/CD

Настроен GitHub Actions pipeline.

При каждом push / pull request выполняется: flutter analyze и flutter test.

Если тесты падают — pipeline завершается ошибкой.
